# The JSON feed

`feed/v1/index.json` is the machine-readable index, generated by CI from the same files as the README. Directories (such as Raven) and AI assistants should read it through its raw URL:

`https://raw.githubusercontent.com/edgytoast/avp-ports-index/main/feed/v1/index.json`

Its schema is [`schema/feed-v1.schema.json`](../schema/feed-v1.schema.json). The data is CC0-1.0.

## Contents

- `entries`: every listed port, with pinned links (`source_url`, `install_doc_url`) to the scanned commit, the trust tier, health, scan state and license as stated. `source_ref` names the branch the index follows when it isn't the repo's default branch.
- `unavailable`: ports that were listed and came off the index after their checks kept failing. Kept as a record that the work existed, with no links.
- `tombstones`: ids that were pulled, taken down or withdrawn, with the date. No reasons are given.

Missing optional fields are `null`, or empty lists, except `install`, which is `["build"]` when absent.

## Versioning

- The feed follows semantic versioning in `schema_version`. Adding an optional field bumps the minor version.
- Any removal, rename or change of meaning creates `feed/v2/`. Version 1 stays available for at least 6 months after that.
- 1.1.0 added `entries[].source_ref`.
- 1.2.0 added `entries[].experiences` (how the port plays) and `entries[].install` (`build`, plus `sideload` when the developer also publishes a prebuilt app the index didn't review).

## Polling

- Poll at most hourly. `generated_at` changes only when the content does.
- Key on `id`. An id that moves to `tombstones` has left the index.
